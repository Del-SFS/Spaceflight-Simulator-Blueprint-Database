Hello, welcome to the SFS Blueprint database.
This repository was created to store blueprint data for SFS and complements the SFSBPI (SFS Blueprint Installer).

## What is the SFSBPDB (SFS Blueprint Database)?
SFSBPDB is a repository designed to store data used by a program called SFSBPI (SFS Blueprint Installer); this database makes it easier to add blueprints to SFSBPI, and SFSBPI simplifies the installation of blueprints into SFS.
